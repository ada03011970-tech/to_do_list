# Планировщик дел

Простой интерактивный планировщик на каждый день: задачи с приоритетами, кольца выполнения и прогресс за неделю.

## Возможности

- Задачи по дням, переключение дней стрелками
- Приоритеты: срочно, второстепенно, можно потом
- Три кольца выполнения по приоритетам и общий процент за день
- Неделя из 7 мини-колец, процент за 7 дней, серия дней на 100%
- Перенос невыполненных задач со вчера одной кнопкой

## Как запустить

Открой `index.html` в браузере. Устанавливать ничего не нужно. Задачи хранятся в браузере (localStorage).
